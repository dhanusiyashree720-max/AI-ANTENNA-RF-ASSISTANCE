AI Antenna and RF Concepts Learning Assistant

Capstone Project 15

Project Overview

This project explores how Artificial Intelligence (AI) can teach antenna and Radio Frequency (RF) fundamentals while reducing incorrect formulas, unit errors, and invented numerical values.

Objectives

- Explain antenna and RF concepts for beginners and advanced learners.
- Verify formulas using reliable engineering references.
- Solve and manually verify eight numerical problems.
- Identify AI-generated errors and document corrections.
- Create a glossary, quiz, and verified answer key.
- Prepare educational diagrams and a technical presentation.
- Automate RF link-budget calculations using a spreadsheet.
- Document AI prompts, limitations, and verification results.

Topics Covered

1. Dipole Antenna
2. Antenna Gain
3. Impedance Matching
4. Voltage Standing Wave Ratio (VSWR)
5. RF Link Budget

Tools

- ChatGPT
- Google Gemini
- Perplexity
- Google Sheets or Microsoft Excel
- Canva
- GitHub

Project Deliverables

- Verified RF explanations and formulas
- Eight solved numerical problems
- Glossary and ten-question quiz
- Antenna and RF diagrams
- Link-budget spreadsheet calculator
- AI prompt library
- Verification and error analysis report
- Before-and-after analysis
- Five-to-seven-slide presentation

Verification Approach

AI-generated explanations and calculations will be checked against reliable technical references. Units, assumptions, equations, and numerical results will be reviewed before inclusion in the final submission.

Limitations

AI can produce incorrect equations, inaccurate values, and misleading explanations. Therefore, its outputs must be verified before being used for engineering learning.
