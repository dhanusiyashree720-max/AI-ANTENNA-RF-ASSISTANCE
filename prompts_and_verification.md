AI Prompt Library and Verification Report

CAPSTONE 15 — AI Antenna and RF Concepts Learning Assistant

Part A: Purpose

This document records the prompts used to generate RF learning materials and the procedures used to verify the results.

AI outputs are treated as drafts until their technical accuracy is checked against reliable references.

Part B: Documented AI Prompts

Prompt 1: Beginner Explanation

Purpose: Explain a technical concept to a beginner.

Prompt:

Explain the concept of a half-wave dipole antenna for a first-year engineering student. Define all technical terms, explain the operating principle, provide one simple example, and identify any assumptions. Do not invent numerical values or references.

Verification: Check the definition and antenna-length relationship against an antenna engineering textbook.

Prompt 2: Advanced Explanation

Purpose: Generate a more technical explanation.

Prompt:

Explain dipole antenna operation at an advanced introductory engineering level. Discuss wavelength, current distribution, radiation pattern, resonance, and practical antenna-length effects. Distinguish ideal assumptions from practical behaviour and identify claims requiring source verification.

Verification: Check technical terminology and equations against the selected reference.

Prompt 3: Formula Verification

Purpose: Identify errors in equations and units.

Prompt:

Review the following RF equation: [insert equation]. Define every symbol, state the units, list the assumptions and applicable conditions, and identify common mistakes. Do not claim that the equation is verified unless a reliable reference is supplied and checked.

Verification: Compare the equation with the original reference and record the relevant page or section.

Prompt 4: Numerical Problem Solving

Purpose: Generate worked RF numerical solutions.

Prompt:

Solve the following RF numerical problem step by step: [insert problem]. List the given values, convert all quantities to consistent units, state the formula and assumptions, show each substitution, and give the result with units. Independently check the arithmetic and explain how the result can be verified. Do not invent missing data; ask for clarification if necessary.

Verification: Recalculate the answer independently and compare it with the formula's source.

Prompt 5: Quiz Generation

Purpose: Create an educational quiz.

Prompt:

Create ten multiple-choice questions on dipole antennas, antenna gain, impedance matching, VSWR, and RF link budgets. Use four options per question, only one correct answer, and provide an answer key with explanations. Keep numerical values consistent and identify questions requiring reference checks.

Verification: Solve every question independently and confirm the answer key.

Prompt 6: Glossary Generation

Purpose: Explain RF vocabulary.

Prompt:

Create a beginner-friendly glossary of antenna and RF terms. Define each term accurately, include units where applicable, distinguish dB, dBi, and dBm, and flag definitions that depend on assumptions or conventions. Do not invent citations.

Verification: Compare definitions with authoritative technical sources.

Prompt 7: Diagram Planning

Purpose: Prepare technically accurate educational diagrams.

Prompt:

Prepare a diagram plan for a half-wave dipole antenna, a radiation pattern, impedance matching, VSWR on a transmission line, and a basic RF link budget. Label relevant quantities clearly. Do not imply that a schematic is to scale, and identify features requiring technical verification.

Verification: Check labels, physical relationships, and stated assumptions against the reference materials.

Prompt 8: Link-Budget Spreadsheet

Purpose: Design spreadsheet automation without programming.

Prompt:

Design an Excel or Google Sheets link-budget calculator. Specify input cells for transmitter power in dBm, transmitting and receiving antenna gains in dBi, path loss in dB, and additional losses in dB. Give the spreadsheet formula for received power, explain the units, and provide test cases with independently calculated expected results.

Verification: Compare spreadsheet outputs with hand calculations and confirm that the input assumptions are consistent.

Prompt 9: Error Analysis

Purpose: Identify possible AI errors.

Prompt:

Review the following AI-generated RF explanation or calculation: [insert output]. Check the equations, arithmetic, assumptions, units, and source support. Separate confirmed errors from possible concerns. Suggest corrections only when they can be justified, and do not invent errors merely to complete an error log.

Verification: Record evidence for each correction.

Prompt 10: Presentation Preparation

Purpose: Organize the project findings.

Prompt:

Create a seven-slide presentation outline for an AI Antenna and RF Concepts Learning Assistant. Include the problem statement, RF topics, AI tools, reference verification, numerical results, spreadsheet automation, limitations, and conclusion. Keep claims consistent with completed project evidence.

Verification: Compare every slide with the actual report and tested deliverables.

Part C: Verification Procedure

For each AI-generated technical answer:

1. Identify the formula or definition being used.
2. Locate an appropriate technical reference.
3. Check the formula and its assumptions.
4. Check every symbol and unit.
5. Recalculate numerical results independently.
6. Compare the independent result with the AI output.
7. Record discrepancies and corrections.
8. Keep the source details with the verified result.

Part F: Limitations of AI

- AI may produce plausible but incorrect equations.
- AI may confuse units or logarithmic quantities.
- AI may omit important assumptions.
- AI may invent unsupported values or citations.
- Correct arithmetic does not guarantee that the selected formula is appropriate.
- A source citation does not prove that a claim has been interpreted correctly.
- Engineering calculations may require simulation, measurements, or expert review.

Part G: Conclusion

This prompt library establishes a repeatable process for generating, checking, and documenting AI-assisted RF learning materials. Independent calculations, source verification, and an evidence-based error log are essential for responsible use of AI in engineering education.
