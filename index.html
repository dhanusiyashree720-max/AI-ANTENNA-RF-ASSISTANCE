1. Dipole Antenna

A half-wave dipole has an approximate total length of half a wavelength.

Formula: λ = c / f

Here, c is the speed of light and f is frequency in hertz.

2. Antenna Gain

Antenna gain describes radiation or reception effectiveness in a specified direction relative to a reference antenna.

Linear gain = 10(gain in dBi / 10)

3. Impedance Matching

Reflection coefficient for a real reference impedance:

Γ = (ZL − Z0) / (ZL + Z0)

Matching reduces reflected power.

4. VSWR Calculator

Enter reflection coefficient magnitude |Γ| from 0 to 1.

5. Link Budget Calculator

Enter transmitter power in dBm, gains in dBi, and total losses in dB, including path loss where applicable.









Formula Verification

VSWR = (1 + |Γ|) / (1 − |Γ|), for |Γ| < 1.

Received power = transmitter power + antenna gains − total losses, with compatible dB-based units.
